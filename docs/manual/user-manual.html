1. What it does

VisualMeetingTool takes the transcript of a meeting (for example the one Microsoft Teams produces) and, if you have it, the video recording. It picks the moments where something worth showing appeared on screen, has Google's Gemini read them, and writes:

  • a summary of the meeting, with the screens that mattered; or
  • a register of questions and answers, each question with its whole answer;

and builds a Word report from it. Meetings are grouped in projects, and each new summary can use what the project already learned in earlier meetings.

Everything runs on your computer. The only thing that goes out is what is sent to Gemini while a meeting is being processed (see Privacy).

2. What you need

  • Windows 11, 64-bit. No administrator rights and no Python are needed.
  • About 150 MB of free disk space for the program, plus room for your meetings. While a meeting is processed its video is copied into the data folder, so that drive needs free space as large as the video (up to 16 GB).
  • An internet connection while a meeting is processed.
  • A Gemini API key from a Google Cloud project with billing enabled (the paid tier). Section 4 says why and how.
  • For each meeting: the transcript as a .docx (the Teams transcript) or a .txt whose lines start with the time, like [00:05:12] Ana: …. The video is optional for questions and answers, and needed for the summary. In Microsoft Teams, a meeting that had transcription turned on lets you download its transcript as a Word file; if you do not see the option, ask the meeting's organizer or your IT team. A .vtt file is not accepted.

3. Installing

  1. Run VisualMeetingTool-Setup-<version>.exe.
  2. Windows may warn you. The program is not digitally signed yet, so Windows SmartScreen can show "Windows protected your PC". Choose More info, then Run anyway. Some antivirus programs also ask before running a new file; allow it if you got the installer from someone you trust.
  3. The first question is the language of the installer (Spanish or English). The installed application starts in the language you pick, and you can change it later in Settings.
  4. The installer proposes a folder inside your own user profile (C:\Users\<you>\AppData\Local\Programs\VisualMeetingTool). Keep it unless you have a reason to change it. Because it is your own folder, no administrator password is asked.
  5. Choose whether to add a desktop icon (off by default). The program is always added to the Start menu.
  6. Finish. Leave "Launch VisualMeetingTool" ticked to open it now.

The program opens in its own window titled "MeetingTool". It does not use your web browser and there is no console window.

The window is drawn by Microsoft Edge WebView2, a component that comes with Windows 11. If it is missing or damaged, the program says so and how to repair it (see Troubleshooting).

4. First start: your Gemini key

The program uses Google's Gemini to read the screens and to write the text. It uses your own key, so the cost goes to your Google account. Without a key nothing can be processed.

  1. Create an API key for Gemini in your Google account (Google AI Studio, aistudio.google.com). Google's pages change from time to time; if you cannot find it, search for "Gemini API key".
  2. Make sure the key belongs to a Google Cloud project with billing enabled. This matters: on the free tier, Google may use what you send to improve its products, and meetings are often confidential.
  3. In the program, open Settings (top of the window), find Gemini key, paste the key into New key and choose Save the key.

The page then says "A key is saved" and its length. The key is never shown again; it is kept in the Windows Credential Manager, not in a file. To replace it, save a new one. To remove it, choose Delete the key.

5. Your first meeting

5.1 Create a project

On the Projects page, under New project, write a Name (and, if you like, the Client) and choose Create the project. A project is the place where the meetings about the same subject live, so that each one can build on the last.

5.2 Add the meeting

Open the project and choose New meeting. Fill in:

FieldWhat to put
TitleA short name, for example "Kickoff with the finance team".
DateThe day the meeting happened.
TranscriptThe Teams .docx, or a .txt with [HH:MM:SS] lines. Up to 50 MB.
VideoOptional. .mp4, .mov, .mkv, .webm, .avi, .wmv or .m4v, up to 16 GB. Without a video only questions and answers can be made.
Meeting typePresale, Sales or negotiation, Requirements gathering, Project kickoff, Status, Technical or Training. It changes how the summary reads the meeting. "No type" is fine.
Language of the resultSpanish, English, or "The meeting's" (the language of the transcript).
FormatSummary (needs the video) or Questions and answers (each question with its whole answer; the transcript must show who is speaking).
Estimated spending ceiling in dollarsThe most you accept to spend on this meeting: a number above 0 and up to 5. It starts at 1. It is an estimate, not a guarantee: see section 6.

The file windows are the normal Windows file dialogs. Choose Process to start.

5.3 Watch it work

The Processing page lists the stages, each with its state (waiting, running, done, not needed, failed), its time and what it cost:

  1. Frames of the video: the program picks the moments worth keeping (slides, shared screens; not frames that only show people on camera) from the video. This is the slowest stage on a long recording; the page shows which stage it is on.
  2. Reading of the frames: Gemini describes what each kept frame shows.
  3. Summary or Questions and answers: Gemini writes the text from the transcript and the readings.
  4. Word report: the report is built on your computer, with no cost.
  5. Saving the meeting in the project: the last step. The page lists it only if it fails.

Only one meeting is processed at a time. You can leave the page; the work continues while the program's window stays open. If you close the window with the X during processing, the program asks first. If you confirm, the meeting is not added to the project; what was already paid for is kept, as for a failed run, so that processing it again does not pay for it twice (see Kept from runs that failed in Troubleshooting). If it was just being saved, it is saved whole.

A meeting is added to its project only when the whole run succeeds. If a stage fails, the page says which stage, why, and how much was spent; the meeting is not added and nothing is left half done. What was already paid for stays safe so that running the same meeting again does not pay for it twice (see Troubleshooting).

6. Cost and the spending ceiling

Gemini charges for what it reads and writes. The program shows, for every run, what it cost: "X of an estimated ceiling of Y". That figure is an estimate at Google's list prices; the exact charge is on your Google Cloud billing.

  • The estimated spending ceiling is a safety limit, not a guarantee. It starts at US$1.00. Before it sends each request, the program estimates the most that request could cost; if that could take the run over the ceiling, it does not send it and stops with a message that nothing was written.
  • A request that was already sent is paid even if its answer is then refused. The program checks Gemini's text before accepting it (for example, that it has all its sections); a refused answer still cost money. The ceiling counts it.
  • If an answer costs more than was estimated, the run stops. The estimate cannot be trusted any more, so nothing more is sent in that run. What was already answered is kept and not paid again if you process the same meeting again.
  • A ceiling that is too low stops a long meeting early. Raise it for that meeting and process it again.
  • Your cost depends on the length of the video and on how many frames are kept. For your first meeting, keep the ceiling low and raise it only if the run stops.
  • Google can change its prices at any time, and the program works from the prices it knows. Check your Google Cloud billing page if the exact figure matters.

7. Reading the result

When the run finishes, open the meeting from its project. You will find:

  • the summary (or the register of questions and answers), with its key points;
  • the frames that were kept, each labelled with its minute in the meeting;
  • a button to Open the Word report (or Download it);
  • a line "N images in the report, of M kept from the video" and what it cost.

The project page also shows What the project already knows: what each meeting leaves behind and the next summary reads.

While a meeting is processed the recording is copied into the data folder, so that drive needs free space for it; the copy is deleted once its frames are taken, and the meeting keeps only the frames, the transcript, the text and the report.

8. Settings: language, company, Word template

Open Settings at the top of the window.

  • Language of the application: Spanish or English. It changes everything the program says. The language of each summary is chosen per meeting.
  • Company: a name and a logo (PNG or JPG, up to 1 MB) shown at the top of every screen. SVG logos are refused.
  • Gemini key: see section 4.
  • The company's Word template: optional. A .docx or .dotx without macros with your logo, header, footer, colours and fonts. What is written on its first page, before the table of contents or the {report} marker, becomes the cover of every report (what comes after them is a model and does not go into the reports), and data written between braces is filled in for you ({client}, {project}, {meeting}, {date}, {type}). If it has a table of contents, each report puts its sections there. The Settings page checks the template and tells you what it will do; use Download an example template to start from a working one. Without a template, reports come out with a neutral design.

Back up the data folder if the reports matter to you: it is outside the program, so a copy of it is a copy of everything. It holds client information, so do not put it in a shared or public folder.

10. Privacy: what leaves your computer

  • The program's pages are served by your own computer and can only be used from it. The footer of every page says so.
  • While a meeting is processed, the program sends to Gemini (Google): the kept frames (images from your video) and the text of the transcript, plus the meeting's title and type and what earlier meetings of the project taught it. Nothing else is sent, and the video file itself is never uploaded. A title with the client's name leaves your computer, so choose titles accordingly.
  • Use a key from a project with billing enabled, as explained in section 4, and follow your organization's rules about what may be sent to a third party.
  • The log file written at each start holds technical facts about the program and the computer, never your key.

11. Updating and uninstalling

  • Updating: run the newer installer. It installs over the old version. Your data and your Gemini key are kept.
  • Uninstalling: Settings → Apps → Installed apps → VisualMeetingTool → Uninstall. This removes the program but keeps your data folder and your key. To remove them too, delete C:\Users\<you>\VisualMeetingTool-data yourself and, if you want, delete the key in Settings before uninstalling. The small folder of the log, C:\Users\<you>\AppData\Local\VisualMeetingTool, also stays.

12. Troubleshooting

What you seeWhat it means and what to do
"Windows protected your PC" when starting the installerThe installer is not signed yet. Choose More info → Run anyway.
The window is blank, or a message says the Windows component (Microsoft Edge WebView2) could not startInstall or repair Microsoft Edge WebView2 Runtime from Microsoft's page, then open the program again. The message gives the place of the log. Some restricted environments, such as Windows Sandbox on Windows 11 24H2, cannot run WebView2 at all.
"MeetingTool is already open on the data folder: use that window"Only one copy can use a data folder. Find the open window (check the taskbar) or close it from the Task Manager.
"No key is saved: without one nothing can be processed"Save your Gemini key in Settings (section 4).
"The summary needs the video. Without a video, choose questions and answers."Attach the video, or change the format to Questions and answers.
The register of questions and answers cannot be made because the transcript names no speakerQuestions and answers need to know who asked and who answered. Use a transcript with speaker names, or choose the summary format.
"It failed at «Reading of the frames»: stopped before sending frames 1-15: that request could cost up to US$… and … could go over the budget"The spending ceiling protected you. That request was not sent and nothing was written. What the earlier requests of the run cost was paid and is kept (see the row about Kept from runs that failed). Raise the ceiling (section 6) and process the meeting again.
"…the answer … used more tokens than its request was estimated to use … nothing more is sent in this run. What was already answered is kept"An answer cost more than the program had estimated, so it stopped on purpose. What was paid is kept: process the same meeting again, with a higher ceiling if you like, and it is not paid twice.
A run failed after it had already paid for somethingThe page lists it under Kept from runs that failed. Processing the same meeting again (same project, format and transcript) reuses what was paid and does not pay for it twice. Discard removes it for good, and processing it again would pay for it again.
A message with a reason from Google (a quota, a key problem, a refusal)It is shown as Google sent it, below the program's own sentence. Check that the key is valid, that billing is enabled and that you have not run out of quota; then try again.
The summary was rejected and the run stoppedThe program checks Gemini's text before accepting it (it must have its sections, the right language, and only frames that exist) and retries once. If it still fails, process the meeting again: answers vary from one try to the next.
The antivirus quarantines or blocks the programThe program is new and unsigned, so some antivirus products are cautious. If you trust the source of your installer, allow it in your antivirus.

If something else goes wrong, the file C:\Users\<you>\AppData\Local\VisualMeetingTool\window.log says what happened at the last start. It never contains your key; read it before sharing it, as it names folders on your computer.

VisualMeetingTool runs on your computer. Summaries and reports are written by an AI model and can contain mistakes: read them before you use or share them.
